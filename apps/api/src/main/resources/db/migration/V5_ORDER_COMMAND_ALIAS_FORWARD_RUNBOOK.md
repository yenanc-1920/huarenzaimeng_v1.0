# V5 建单接收键别名前滚说明（STATIC_CONTRACT_ONLY / NOT_RUN）

本地切片只完成 MySQL 5.7 静态契约，不执行真实 MySQL。V5 仅收紧同主体、同端点的
`IdempotencyKey` 唯一作用域，配合 `hz_command` 中独立 `ORDER_ALIAS:*` 语义行保存换键重放别名。

执行前必须在独立恢复副本检查重复键并证明计数为0；若存在重复，停止迁移并形成受控处置证据。
执行后必须验证：同业务键同指纹换双键原子登记别名、别名重放不新增订单、任一已接收键用于另一
`QuoteRef` 均失败关闭。未取得隔离 MySQL 5.7 执行证据前，真实数据库状态保持 `NOT_RUN`。
