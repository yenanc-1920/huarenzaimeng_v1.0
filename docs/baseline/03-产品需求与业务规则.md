# 产品需求与业务规则

## 产品范围

V1 包含充值交易、报价与订单、订单恢复、微信身份与协议同意、个人中心、黄页、生活资讯及对应运营后台。当前不将真实自动退款、复杂财务审批、多供应商自动路由或用户可切换环境纳入 V1。

## 用户与登录

- 游客可浏览允许的公开内容；个人信息和交易入口可触发登录。
- 登录页使用一个合并协议勾选项，不要求先打开正文；随后遵循微信官方隐私授权。
- 服务端保存权威同意记录。旧政策版本会话不得继续首个新交易。
- “我的”页面提供协议查看、退出和注销申请。
- 微信 code 一次性使用；重试必须重新获取，禁止重放。

## 环境与 AppID

- DEV、TEST、STAGE、PROD 共用同一获批小程序 AppID。
- 服务、数据库、账号、域名、秘密和发布链必须隔离。
- 正式包固定 PROD，终端用户不得选择环境。

## 充值与订单

- 客户端不得自报供应商成本、权威价格或履约权益。
- 报价和订单保存不可变的价格、商品、号码 mask/HMAC、汇率和权益快照。
- 幂等键冲突、版本漂移、状态冲突和未知供应商结果均失败关闭。
- UNKNOWN 只查询原单，不重复提交充值、支付或退款。

## WINLA 金额与号码

- `yj` 为官方售价、`yh` 为供应商优惠价，均为人民币元。
- 提交 `price` 为实际应扣款人民币元；验签回调 `order_money` 为权威实际扣款人民币分。
- 内部金额统一使用整数 CNY 分；额外小数、溢出、非数字或币种错配进入 UNKNOWN。
- 接受 `01xxxxxxxxx`、`8801xxxxxxxxx`、`008801xxxxxxxxx`，内部规范为 `8801[3-9]xxxxxxxx`；仅传输末端转为本地 `01xxxxxxxxx`。

## 定价

- 定价由我方后台决定，不以 WINLA `yj` 直接作为售价。
- A130 草稿预填：缓冲0%、加价10%、固定项0、微信费率0.6%、税0%、最低毛利0、促销承担0、CNY→CNY汇率1、向上取整到分、版本1。
- 预填值不是后端静默默认，启用前必须由 SUPER_ADMIN 显式提交并通过完整校验。

## 权限与数据

- 初期唯一 SUPER_ADMIN 可对同一内容对象提交、审核、发布，但各步骤独立留痕并记录例外策略版本。
- 其他内容角色继续职责分离。
- V1 允许履约专用字段受控保存完整手机号；公开 DTO、后台普通展示、日志、异常、事件和审计只允许 mask 或不可枚举 digest。
- KMS/密文存储和更细保留策略属于后续版本，当前不得声称已实现静态加密。

## 外部能力默认关闭

微信真实支付、WINLA 真实充值、恢复 scheduler、sandbox、fixture 和 synthetic 默认关闭。启用必须具备冻结协议、独立秘密、正式适配器、回调权威校验、失败关闭测试及明确授权的受控实测。

## 法律文本

用户协议和隐私政策目标生效版本为 `2026-08-28`，当前文本仍需运营方最终审阅。未终审前状态为候选稿，不得表述为正式法律意见。
