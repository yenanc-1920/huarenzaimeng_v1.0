# V2.0 技术架构与外部集成

## 1. 目标架构

```text
微信公众号菜单
  -> 华人在孟 H5（微信云托管）
       -> 首页／双时钟
       -> 资讯 API
       -> 黄页 API
       -> 法律与合作说明
       -> 用户点击唯一外链
            -> WINLA 固定推广页
```

运行与部署平台继续统一称为“微信云托管”，不得称为腾讯云服务器。H5、内容API和运营后台继续沿用 DEV／TEST／STAGE／PROD 隔离原则。

## 2. 前端形态

- V2 使用标准 H5 构建目标，不再以 `mp-weixin` 作为用户端发布产物。
- DEV完整门禁保留V1源码与视觉追溯合同，但不再构建或发布V1 `mp-weixin`产物；用户端制品门禁唯一构建目标为`build:h5:v2`。
- 首要运行容器为微信公众号内置浏览器，同时支持普通移动浏览器。
- 页面不得依赖 `wx.login`、小程序会话、AppService、WXML/WXSS、`open-type` 或小程序 TabBar。
- H5 是否复用现有 uni-app 源码须由实现盘点决定；不得为复用而保留已取消的V1交易和身份模块。

## 3. 服务端范围

V2服务端只保留H5运行所需公共能力和运营后台能力，包括健康、首页时点、资讯、黄页及其管理。普通访客无需BUYER会话。

以下V1能力不得由V2用户端调用：微信身份、匿名交易会话、资格、目录、报价、订单、支付、WINLA充值、退款、注销和恢复任务。首期可以保留其历史代码和数据库结构，但必须从V2路由、导航和网络请求闭包中隔离。

## 4. WINLA外链合同

- 固定链接：`https://www.95cxmd.com/h5/#/home/view?id=25&source=pcxvaj`。
- 只允许用户点击后进行普通浏览器导航；不做服务端代理、iframe嵌入、页面抓取、接口转发或自动跳转。
- 不在URL追加手机号、openid、session、内部用户标识、订单标识或秘密。
- 不接收WINLA支付、订单、退款或履约回调。
- 不把WINLA页面响应、支付成功或订单状态写入我方数据库。
- 链接如需变更，必须由WINLA提供新固定对象并经过需求、技术、安全和回归核验；不得静默动态替换。

## 5. 身份与数据

- 取消普通用户登录和买家会话；后台管理员身份体系继续保留。
- 管理员密码恢复使用独立恢复令牌和服务端截止时间，默认关闭；只允许重置既有活动账号密码、清除锁定、撤销旧会话并记录审计，不创建账号或修改角色。
- 管理员首次初始化默认关闭；仅固定DEV隔离组合`release-mysql,local-mysql`、环境身份`dev`且初始化令牌非空时允许短时开启。TEST、STAGE、PROD以及缺少令牌的DEV均在启动阶段拒绝；初始化完成后必须立即关闭开关并清除令牌。
- V2前端不得读写V1的buyer token、匿名token、订单恢复投影或用户头像昵称缓存。
- 默认不引入新的用户追踪SDK。若后续需要访问统计，必须先批准数据字段、目的、保留期、第三方SDK和隐私文本。
- Web服务器必要日志按最小化原则处理，不记录完整query中的潜在个人信息；WINLA推广URL仅记录固定目标或脱敏结果。

## 6. 域名与部署

- 计划域名为 `guiye.xyz` 或经批准的子域名；当前根域名无可用A/AAAA解析且 `www` 不存在，配置前需重新只读核验。
- 大陆服务器／微信云托管接入前核对ICP备案状态、接入商、服务内容、首页备案号与HTTPS。
- 公众号菜单、域名DNS、证书、平台环境变量和正式发布均是独立外部变更，不因代码完成自动执行。
- DEV集成仍通过`dev`与微信云托管发布链推进；V2必须使用独立冻结提交和制品身份，不能沿用V1部署证据。
- 首期H5固定挂载在现有应用的`/h5/`路径；Vite制品使用`/h5/`资源基路径，并由五套环境Dockerfile复制到Spring静态资源目录的`h5`子目录。后台根路径和既有API路径不迁移。

## 7. V1保留策略

- V1代码、Flyway迁移、数据库表和历史证据只读保留。
- V2不得执行Flyway clean、repair、回退、删除交易表或批量清理账户／订单。
- 后续数据保留、归档或删除另立问题，并按真实数据库破坏性操作申请授权。

## 8. 安全与失败边界

- WINLA不可达时只显示外部服务不可用，不回退我方V1充值链。
- 禁止开放重定向；外链目标必须精确匹配批准的HTTPS origin和路径结构。
- 禁止将WINLA页面可达、支付成功或订单存在外推为我方业务验收。
- 任何第三方脚本、统计SDK、客服组件或iframe接入均需另行安全与隐私评审。
