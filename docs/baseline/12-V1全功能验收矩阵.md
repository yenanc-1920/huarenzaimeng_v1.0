# V1 全功能验收矩阵

## 状态定义

- `STATIC_IDENTIFIED`：已定位页面、接口或实现，仅证明入口存在。
- `LOCAL_PASS`：定向本地测试通过，不能证明真实环境。
- `DEV_PASS`：固定 DEV 版本的业务行为通过。
- `REAL_PASS`：真实微信、数据库、供应商或资金链路通过。
- `BLOCKED`：存在明确阻断项。
- `NOT_RUN`：尚未执行对应等级验证。

关闭一项功能必须登记固定提交、环境/实例、验证入口、Expected/Actual、证据等级和证据路径。不得以页面存在、构建成功、Fake 或 H2 代替真实业务 PASS。
