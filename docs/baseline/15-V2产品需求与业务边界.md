# V2.0 产品需求与业务边界

## 1. 版本与产品名称

- 对外产品名称保持“华人在孟”，页面不得展示“V2.0 H5版”。
- `V2.0 H5版`只用于项目文档、Git、构建、部署和验收对象区分。
- V1.0 微信小程序版自 2026-08-24 起冻结归档；V2 是重大载体与业务边界调整，不作为 V1.1 增量迭代。

## 2. 产品定位

V2 是由微信公众号链接调起的“华人在孟”H5生活信息服务，目标是通过首页、双时钟、资讯和黄页提供持续使用价值，并以一个公开入口连接由 WINLA 独立提供的全球充值服务，为后续生活服务拓展积累访问用户。

本项目不从 WINLA 充值产生佣金，不经手充值款，不建立我方充值合同或订单关系。

## 3. V2 用户端范围

### 3.1 包含

- 首页与达卡／北京时间双时钟；
- 生活资讯列表、分类、详情和适用状态；
- 华人黄页列表、筛选、详情和适用状态；
- 首页唯一充值推广卡片；
- 用户协议、隐私政策、合作服务说明；
- 必要的关于我们或问题反馈信息；
- 微信公众号菜单进入华人在孟 H5 首页。

### 3.2 明确取消

- 孟加拉运营商介绍；
- 手机号规则、防充错提示、手机号输入和本地运营商识别；
- 普通用户登录、微信身份、头像、昵称、个人中心、退出和注销；
- 我方商品目录、报价、倒计时、确认订单、订单创建和订单查询；
- 我方支付、充值进度、退款、UNKNOWN恢复及充值客服；
- 我方向 WINLA 传递手机号、微信身份、我方用户标识或订单数据。

后台运营人员身份与资讯、黄页管理不因取消普通用户登录而自动取消。

## 4. 页面与导航

- 底部导航固定为三个 Tab：`首页｜资讯｜黄页`。
- 删除 V1 的“我的”Tab及所有普通用户登录入口。
- 用户协议、隐私政策和合作服务说明通过首页页脚或“关于华人在孟”入口访问，不新增第四个Tab。

## 5. 唯一充值入口

- 首页保留一个充值推广卡片，不在资讯、黄页、客服或其他页面建立第二入口。
- 固定目标为 WINLA 提供的推广链接：`https://www.95cxmd.com/h5/#/home/view?id=25&source=pcxvaj`。
- 卡片点击后由用户主动直接进入 WINLA 页面；我方不增加登录、号码、报价、订单或支付中间步骤。
- 页面必须明示“小啦全球充”或“WINLA”为第三方服务提供者，不得让用户误认为充值由华人在孟提供。
- 建议卡片文案：标题“境外话费充值”；说明“点击进入第三方充值平台”；步骤文案“直接跳转第三方平台完成充值”；按钮“前往小啦全球充”。
- 卡片附近必须说明：“充值、订单、退款及售后服务由小啦全球充提供。”

## 6. 第三方服务边界

WINLA 页面独立承担手机号输入、运营商识别、商品与报价、下单、收款、订单查询、履约、退款和充值售后。其页面能力、支付结果和订单结果不得登记为华人在孟功能 PASS。

华人在孟只负责展示合作入口并执行普通外部跳转；不得代理下单、代收款、代承诺到账、代受理退款或复制保存 WINLA 订单。

## 7. 数据与隐私

- V2 普通访客无需登录，我方不建立买家账户。
- 我方不得采集充值手机号或从推广链接回收订单数据。
- 推广链接仅使用 WINLA 已提供的固定公开渠道参数；不得追加微信身份、手机号或其他个人信息。
- 即使取消登录，服务器访问日志、反馈信息或访问统计仍可能涉及个人信息，必须在隐私政策中如实披露最小范围、目的和保留期。

## 8. 业务与合规前置条件

- 取得 WINLA 对推广链接、品牌名称和必要素材的书面授权；无佣金事实应写入合作边界。
- 正式配置公众号菜单前，核对公众号平台对完整路径的允许范围。
- `guiye.xyz` 当前为个人 ICP 备案且计划使用大陆服务器；上线前核对实际服务内容、接入信息、备案展示和公众号运营主体匹配。
- 不采用审核时隐藏、发布后恢复、客服私发、短链掩盖、自动跳转或动态替换交易入口。

## 9. V2 完成定义

V2 完成不要求我方充值交易通过，而要求固定版本在公众号内完成：首页可达、三Tab导航、双时钟、资讯、黄页、法律文本、第三方披露和唯一WINLA外链均通过；我方网络请求、存储和日志中不存在充值手机号、充值订单或资金操作。
