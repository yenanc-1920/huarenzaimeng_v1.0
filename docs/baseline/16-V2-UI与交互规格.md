# V2.0 H5 UI 与交互规格

## 1. 总体原则

- 对外统一显示“华人在孟”，保持现有品牌识别；不展示内部版本号。
- 以微信内置浏览器为首要视口，同时兼容常见移动浏览器。
- 首页、资讯、黄页沿用现有视觉语言，但不得机械携带V1小程序登录和交易组件。
- 首页、资讯列表和黄页列表不重复展示浏览器已有的品牌标题栏；详情页保留必要的返回区域。
- 按钮、列表、分类和Tab文字继续保持水平、垂直居中；法律正文顶部返回区域保持固定可达。

## 2. 信息架构

| 页面ID | 页面 | 核心内容 | 主要入口 |
|---|---|---|---|
| H001 | 首页 | 欢迎信息、双时钟／今日状态、唯一充值推广卡、法律链接 | 认证服务号菜单／H5根路径 |
| H010 | 资讯列表 | 分类、列表、加载／空／失败状态 | 底部“资讯” |
| H011 | 资讯详情 | 标题、时间、正文、返回 | 资讯列表 |
| H020 | 黄页列表 | 城市／分类筛选、列表及适用状态 | 底部“黄页” |
| H021 | 黄页详情 | 商家公开信息、返回 | 黄页列表 |
| H030 | 用户协议 | H5服务条款 | 首页页脚／关于页 |
| H031 | 隐私政策 | H5个人信息处理规则 | 首页页脚／关于页 |
| H032 | 合作服务说明 | WINLA主体与责任边界 | 充值卡片／首页页脚 |

底部导航固定为 `首页｜资讯｜黄页`，无“我的”Tab。

首页不重复展示浏览器已有的品牌标题栏，也不展示资讯／黄页摘要或快捷卡片；资讯和黄页只从底部Tab进入。首页固定为一个动态视口高度并禁止页面纵向拖动，内容按可用高度和宽度收紧间距、卡片内边距及字号；资讯、黄页、详情和法律页面仍保持正常纵向滚动。首页不得横向滚动、裁切核心内容或遮挡底部导航。

## 3. 首页充值推广卡

- 全站仅首页出现一次充值入口。
- 标题：`境外话费充值`。
- 说明：`点击进入第三方充值平台`。
- 原“输入号码，选择商品，微信付款”改为：`直接跳转第三方平台完成充值`。
- 主按钮：`前往小啦全球充`。
- 责任说明：`充值、订单、退款及售后服务由小啦全球充提供。`
- 点击按钮直接打开固定 WINLA 推广链接；不弹登录、不输入号码、不展示我方报价、不建立我方订单。
- 不自动跳转；必须由用户明确点击。
- 跳转失败时只提示“第三方服务暂时无法打开，请稍后再试”，不得回退到V1充值流程。

## 4. 删除与替换

- 删除普通用户登录弹层、登录页、“我的”页、头像昵称、订单入口、注销入口和对应导航。
- 删除号码输入、运营商Logo、商品选择、报价确认、支付、订单、进度、退款与历史恢复页面的V2路由和入口。
- 删除孟加拉运营商介绍、号码规则和防充错提示；首页不得用相似内容继续暗示我方提供充值。

## 5. 状态与可访问性

- 首页、资讯、黄页覆盖 loading、empty、ready、failure 和 retry 等适用状态。
- 外链按钮须有可识别的点击态、键盘焦点和足够触控面积。
- 双时钟在页面停留期间按实际时间自行更新；手动刷新只能作为主动校准补充，不能成为保持时间正确的唯一方式。
- H5 不依赖小程序 TabBar、`wx.login`、`open-type=contact` 或小程序专属返回行为。

## 6. 视觉验收

- 冻结构建提交、H5 URL、微信版本、设备／视口、页面状态和截图时间。
- 至少覆盖微信内置浏览器与一个普通移动浏览器。
- 外链验收只证明固定按钮打开固定 WINLA 域名及路径，不证明第三方交易、订单、退款或售后通过。

## 7. V2运营后台导航

- V2后台侧栏只展示`内容审核`、`黄页管理`、`节假日与资讯`，默认落点为`内容审核`。
- `运营工作台`、`客服案件`、`交易差异`、`订单与退款`、`商品、渠道与定价`属于V1交易运营能力，不在V2菜单展示；访问其旧哈希地址时回到`内容审核`。
- 本次仅收敛V2入口，不删除V1组件、接口或历史数据；V1冻结代码不得因此改记为已删除或已验收。
