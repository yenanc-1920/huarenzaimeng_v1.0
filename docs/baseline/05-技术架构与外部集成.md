# 技术架构与外部集成

## 总体架构

- 微信小程序与 Vue 运营后台通过项目 API 访问后端。
- Java 17／Spring Boot 后端负责身份、目录、报价、订单、支付、充值、内容和后台领域。
- MySQL 5.7＋Flyway 管理持久化演进；外部能力通过正式端口/适配器隔离。
- 业务状态采用幂等、单调推进、不可变快照、outbox、任务租约和 UNKNOWN 恢复。

## 环境

- DEV、TEST、STAGE、PROD 服务、数据库、账号、域名、秘密和发布链隔离。
- 环境变量模板只记录键和占位符，实际秘密只存在于平台受控配置。
- 未配置、错配或能力不可达时启动或请求失败关闭，不产生 Fake 成功。

## 微信身份

- 默认模式为固定 HTTPS：`https://api.weixin.qq.com/sns/jscode2session`。
- 仅 CloudBase DEV 冻结环境可显式使用固定 SafeLink HTTP：`http://api.weixin.qq.com/sns/jscode2session`。
- SafeLink HTTP 同时要求：环境名 `dev`、冻结 TCB 环境 ID、显式 transport mode、固定 host/path、唯一精确 `x-openapi-rule: bypass`。
- 禁止 redirect、代理、fallback、应用重试、关闭 TLS/hostname 校验或导入动态自签 CA。
- 非 CloudBase、非 DEV、错环境、错 host/path/header 一律失败关闭。

## 微信支付与 WINLA

- 真实适配器默认 disabled，且配置、身份绑定、回调验签、金额和状态必须全部通过才可启用。
- 微信支付必须绑定预期 AppID、商户号和允许的平台证书序列。
- WINLA 回调不伪造其未提供的 SKU/手机号证据，只绑定提交前不可变内部快照。
- 未知结果只查原单，禁止重复资金动作。

## 数据与迁移

- Flyway 自动初始化在发布链中受专用启动顺序控制；迁移失败不得 repair、clean、baseline 或猜测续跑。
- 真实迁移必须冻结目标身份、权限、备份/恢复、制品、RunId 和 PRE/MID/POST Oracle。
- 当前 MySQL 5.7 专用真实验证仍为 NOT_RUN。
- 公开目录与报价统一绑定“版本号最大的当前有效运营商支持集＋该支持集下版本号最大的当前有效商品目录”；仍有效的历史支持集或目录不得造成商品或价格误判为不唯一。
