# V1 需求、UI 与实现映射

## 1. 统计口径

- 原需求定义16个小程序业务页面：P001、P010-P015、P020-P024、P040-P043。
- 当前 `pages.json` 登记18个正式路由：16个业务页面加用户协议、隐私政策2个法律正文页面。
- Penpot目录共有42个SVG：16个前台正常态、3个前台状态/弹层、21个后台正常态、1个后台状态组件板，以及1个早期A130综合设计源。
- `pages/support/case.vue` 不在正式路由和原需求页面内；客服以微信官方 `open-type="contact"` 为准。
- 本表只证明来源和实现入口已定位，不证明页面行为、真实数据或视觉已经验收。

## 5. 变更规则

新增、删除或改变页面、工作区、字段、状态、API或数据模型时，必须同步更新本表、`03-产品需求与业务规则.md`、`04-UI与交互基线.md`、`12-V1全功能验收矩阵.md` 和 `CHANGELOG.md`。只修改SVG、代码或路由中的一个位置不能视为需求变更完成。
