## 一、我们如何处理个人信息

我们遵循目的明确、最小必要、公开透明和安全保护原则。不同功能可能处理以下信息：

| 场景 | 信息 | 目的 |

1. 用户登录前须分别主动勾选《用户协议》和本政策；两个勾选项默认均为未勾选，只有两项同时同意后才进入后续授权与登录。

3. 昵称、头像等非完成核心充值所必需的信息原则上由用户自主选择；拒绝后使用默认展示，不影响依法可独立提供的基础功能。
4. 用户可以在登录前及“我的”中查看本政策。

## 三、我们如何委托处理或提供信息

为完成必要功能，我们可能向以下服务方提供最小必要信息：

1. **腾讯微信及微信支付**：用于小程序登录、微信客服、支付、查单和退款。实际处理适用腾讯相应规则。
2. **微信云托管及其数据库、网络服务**：用于运行后端、存储订单和提供接口。
3. **手机充值供应商（当前候选为赢啦充值平台）**：为完成孟加拉手机充值，提供商户订单号、充值手机号、供应商商品、必要金额和签名参数；不提供与充值无关的个人资料。
4. **运营商或供应商的履约合作方**：仅在实际完成充值所必需的范围内处理信息。

除取得用户另行同意、履行合同所必需或法律另有规定外，我们不会出售个人信息或向无关第三方提供个人信息。

充值供应商实际签约主体、数据接收实体、处理地域、保存期限及子处理方尚须在正式发布前完成书面确认并更新本政策；未确认前不得据此启用真实充值。

## 四、保存期限

| 信息类别 | 保存期限 |
|---|---:|
| 账号、昵称、头像 | 账号存续期间；注销后删除或匿名化 |
| 登录会话 | 退出、注销或会话到期后失效 |
| 协议同意记录 | 注销后3年 |
| 未形成订单的报价 | 报价失效后180天 |
| 订单、支付、充值、退款 | 交易完成后3年；法律另有规定的从其规定 |
| 交易关联手机号 | 随订单保存3年，到期删除或不可逆匿名化 |
| 客服、投诉、交易差异 | 结案后3年；关联交易未到期时随交易期限 |
| 结构化供应商交易证据 | 交易完成后3年 |
| 非必要原始回调载荷 | 最长180天，之后删除并仅保留必要摘要和事实 |
| 网络和安全日志 | 6个月 |
| 黄页报错 | 处理完成后1年 |
| 已发布内容与版本历史 | 发布期间及下架后3年 |

达到期限后，我们将删除或匿名化信息，但法律法规要求继续保存或争议尚未解决的除外。依法保留的数据将与正常账号使用隔离，仅用于法定义务、对账和争议处理。

## 六、用户权利

用户可以通过“我的”或微信客服申请：

- 查阅、更正个人资料；
- 查询订单、支付、充值和退款状态；
- 获取个人信息处理规则说明；
- 撤回可撤回的授权；
- 删除依法可以删除的信息；
- 注销账号；
- 投诉或提出隐私请求。

撤回授权不影响撤回前基于有效授权进行的处理，也不当然删除未结订单或依法需要保留的交易记录。

## 七、账号注销

“我的—注销账号”提供注销入口。存在进行中订单、未知交易、退款、未结客服或交易差异时，用户应先完成相关事项。符合条件后：

1. 用户二次确认注销；
2. 系统撤销登录会话并停止新增交易；
3. 原则上在15个工作日内完成删除或匿名化；
4. 法律要求或争议处理所需的最小交易记录隔离保留；
5. 注销完成后再次登录视为新账号，不恢复已删除的个人资料。
