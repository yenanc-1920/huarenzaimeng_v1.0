## 本次冻结值

1. 登录前《用户协议》《隐私政策》两个独立勾选项默认未选；同时勾选后再进入微信官方隐私授权。
2. “我的”提供协议查看、退出与注销；注销二次确认且未结事项失败关闭。
3. 唯一 `SUPER_ADMIN` 可同人提交、审核、发布并分别留痕；其他角色继续职责分离。
4. V1 充值手机号受控明文保存；用户端/普通后台脱敏，日志/事件/错误响应禁全文；KMS 后续。
5. 定价默认值为 buffer 0%、markup 10%、fixed ¥0、微信费 0.6%、税 0%、最低毛利额/率 0、`CEILING_0_01`、promotion `NONE`/share 0%、CNY/CNY FX=1。
6. WINLA 受理不等于成功，状态先适配再进入领域；UNKNOWN 只查原单，禁止自动换渠道、重充和退款；供应商未书面确认的金额、回调和号码契约继续 NO-GO。
