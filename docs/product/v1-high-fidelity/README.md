## V1 图片能力边界

- V1 不建设黄页、资讯、节假日、商品的业务图片资源能力；对应前台与后台均不包含封面、机构图片、节日配图、商品图片、上传、素材选择、排序或版权图片管理控件。
- 上述业务以纯文字和结构化字段呈现：黄页使用机构、城市、分类、当地地址、电话、来源和核验时间；资讯使用标题、摘要、正文、分类、来源和发布时间；节假日使用国家、类型、名称、日期或星期、来源和版本；商品使用类型、运营商、权益、有效期、售价、渠道与版本。
- 唯一保留的用户图片能力是微信授权头像：授权后显示微信头像；未授权或撤回授权时显示应用内置默认头像。头像授权与登录身份分离，拒绝授权不影响登录、下单或订单查询。
