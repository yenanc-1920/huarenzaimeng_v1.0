# V1 视觉验收截图矩阵

> 文档状态：视觉验收准备稿；本批未启动微信开发者工具、浏览器、真机或服务，未采集任何实际截图。

## 1. 证据边界

- 每个矩阵项在缺少“同一 build、同一 pageId、规定 viewport”的实际截图时，一律记为 `NOT_EVIDENCED`。
- 截图文件存在只代表 `CAPTURED`，不代表高保真通过。只有同时具备基线 SVG、实际截图、尺寸/版本元数据、约定容差及人工签核，才能记为 `VISUAL_PASS`。
- 本批没有运行微信开发者工具或真机，所有小程序项统一附加 `NO_REAL_DEVICE_EVIDENCE`。开发者工具截图也不能替代真机证据。
- 源码、构建成功、合同测试、路由存在或静态 SVG 均不能替代视觉像素证据。
- 禁止生成假截图、拼接截图或用高保真 SVG 冒充实际页面截图；业务数据不足时标记 `BLOCKED_DATA`，不能以合成数据填充。
- 在线 Penpot 尚未在本批核验。本目录 SVG 是本地可交付基线副本，不能据此宣称在线文件已同步。

### 1.1 统一采集规格

| 端 | 基线画布 | 实际采集 viewport | 缩放/主题 | 输出格式 |
|---|---:|---:|---|---|
| 微信小程序 | 390×844 | 开发者工具模拟器 390×844；另行真机补证 | 100%，浅色，简体中文，无调试蒙层 | PNG |
| 后台管理 | 1200×820 | 浏览器内容区 1200×820 | 浏览器缩放 100%，DPR=1，浅色，隐藏开发者工具 | PNG |

命名规则：`{端}-{页面或frame}-{主状态}-{尺寸}-{角色}-{build短号}.png`。示例：`mini-P011-READY-390x844-BUYER-a1b2c3d.png`、`admin-A130-PRICE-READY-1200x820-SUPER_ADMIN-a1b2c3d.png`。文件名不得包含手机号、姓名、token、订单校验码或其他秘密。

### 1.2 状态码

| 状态 | 含义 |
|---|---|
| `READY` | 权威数据已读取，页面正常展示 |
| `LOADING` | 正在读取，旧数据已撤销 |
| `EMPTY_FIRST` | 权威数据首次为空 |
| `EMPTY_FILTER` | 过滤后为空，可恢复 |
| `ERROR_RECOVERABLE` | 可重试失败，不展示旧数据 |
| `ERROR_BLOCKED` | 不可继续，主动作禁用 |
| `DISABLED` | 功能或通道未开放，失败关闭 |
| `UNKNOWN` | 权威结果未知，只允许查询原交易 |
| `UNAUTHENTICATED` | 未登录/会话失效 |
| `ACCESS_DENIED` | 已登录但角色无权 |

## 4. 人工执行说明

### 4.1 微信开发者工具

1. 先记录固定输入：Git commit/build 短号、API 环境、数据版本、操作者、日期时区。没有固定 build 时停止，不采集。
2. 在微信开发者工具中导入同一 build 的 `apps/miniapp/dist/build/mp-weixin`。本步骤由人工执行，本批没有启动工具。
3. 选择 390×844 模拟器，缩放 100%，浅色主题，关闭调试面板、性能悬浮层和网络面板；确保系统语言与字体一致。
4. 通过矩阵中的路由进入页面。带参数页面必须使用属于当前账号且已脱敏的验收数据，不把真实手机号、token、校验码写入文件名或截图备注。
5. 每页先核对 URL/route、pageId/frameId、build、viewport，再按建议文件名保存 PNG。稳定追踪属性只用于关联，不能据此判视觉通过。
6. 加载、空、失败、禁用和 UNKNOWN 必须由权威环境真实状态或受控测试前置产生；不得改前端源码、代理响应或用合成数据制造状态。
7. P022 的微信官方隐私授权和 `wx.login` 只能在有授权的小程序环境中执行。无法执行时标 `BLOCKED_ENV`，协议 checkbox 截图不能替代官方授权证据。
8. 开发者工具截图全部标 `CAPTURED_SIMULATOR`；后续在规定真机补采同 build 证据。未补真机前保留 `NO_REAL_DEVICE_EVIDENCE`。

### 4.2 后台浏览器

1. 先记录固定 build、后端环境、数据版本及目标角色。没有对应角色账号或权威数据时标 `BLOCKED_ROLE`/`BLOCKED_DATA`，不要借用更高权限冒充普通角色画面。
2. 浏览器内容区设为 1200×820，DPR=1、缩放 100%、浅色主题；隐藏开发者工具、书签栏和扩展弹层，截图仅含应用内容区。
3. 从 `/admin/login` 登录，再用 `/#/{pageId}` 进入顶层页面；子 frame 按矩阵中页签、列表行或按钮进入。不得直接修改 Vue 状态跳过真实入口。
4. 写页面仅使用专用验收记录并保留 idempotency/expectedVersion；A100/A110 只追加事件，A140 全程只读。不要为了截图修改订单、支付、充值或退款终态。
5. 截图前核对当前角色、数据前置、build 和 viewport；保存 PNG 后另记页面时间、数据引用（脱敏）和采集人。
6. `ACCESS_DENIED`、`UNAUTHENTICATED`、失败和空态必须单独采集，不能用正常态截图加文字说明替代。

## 5. 高保真人工比对与签核

每一项至少完成以下记录后，才可从 `CAPTURED` 进入人工评审：

- 基线 SVG 文件名与 SHA256；实际截图文件名与 SHA256；固定 build/commit；pageId/route；viewport、DPR、缩放；角色与脱敏数据引用。
- 结构：主区块顺序、卡片层级、页签/导航、底部四栏、弹层和安全提示位置。
- 视觉：蓝/金/浅灰/白卡基调、圆角、间距、字号、换行、按钮文字水平/垂直居中、选中/禁用/错误颜色。
- 内容：业务中文、无“开发样例/目录快照/Mock/synthetic”等工程词；不冒充未知金额、权益、来源、状态或运营商。
- 隐私与安全：手机号脱敏、无 token/secret/raw supplier 数据、无越权动作、UNKNOWN 只读查询原交易。
- 图片边界：黄页、资讯、节假日、商品无业务图片；仅 P024 可显示已授权微信头像，未授权使用默认头像。
- 状态：正常、加载、首次空、筛选空、可恢复/不可恢复失败、禁用、未知、未登录/无权限按页面适用范围覆盖。

签核状态只允许：`NOT_EVIDENCED` → `CAPTURED` → `REVIEWED_WITH_FINDINGS` 或 `VISUAL_PASS`。视觉差异必须记录 finding ID、基线位置、实际截图位置、严重级别和处理结论。
